## Concept-screen adoption (29 Oct 2026, dark set — superseded visually by D-05)

The approved concept screens set the look (dark navy, map-led Command Centre, Signal Review split view,
impact graph, case timeline, dark sign-in). These concept elements were deliberately **not** copied because
they conflict with D-14/D-19/D-25 and the PRD guardrails:

| Concept element                              | Built instead                                            |
| -------------------------------------------- | -------------------------------------------------------- |
| "87%" / "60–75%" confidence                  | Band + factor basis                                      |
| KPI tiles with % deltas, "Live Intelligence" | Operational counts; no live claims                       |
| Email + password form                        | SSO button (not connected in demo) + labelled demo roles |
| News photos / satellite thumbnails           | Signal-type icon tiles (no imagery behind signals)       |
| Unlabelled moving ships/trucks               | Replay with persistent "Illustrative simulation" label   |

## Truth vocabulary (resolves four competing label schemes)

Three separate fields, never merged:

- **SourceClass** (where it came from): public, third_party, licensed, client, synthetic
- **ClaimClass** (how it is known): observed, sourced, inferred, assumed, synthetic, illustrative
- **DataMode** (what time it shows): live, snapshot, replay, scenario, synthetic_demo
